# vite-plugin-singlefile-escaped

[![npm version](https://img.shields.io/npm/v/vite-plugin-singlefile-escaped)](https://www.npmjs.com/package/vite-plugin-singlefile-escaped)
[![CI](https://github.com/maxmeis/vite-plugin-singlefile-escaped/actions/workflows/ci.yml/badge.svg)](https://github.com/maxmeis/vite-plugin-singlefile-escaped/actions/workflows/ci.yml)

A Vite plugin that escapes the HTML generated by [`vite-plugin-singlefile`](https://www.npmjs.com/package/vite-plugin-singlefile), with optional prefix and suffix strings. The result can be embedded as a JavaScript string or in another text format.

Requires Node.js 22.12 or later and Vite 7 or 8. Version 2 processes one HTML asset in Vite's bundle and fails the build if the bundle has zero or multiple HTML assets.

## Install

```sh
npm install --save-dev vite-plugin-singlefile vite-plugin-singlefile-escaped
```

## Use

Place this plugin after `viteSingleFile()` so it can process the single HTML asset emitted by that plugin:

```ts
// vite.config.ts
import { defineConfig } from 'vite';
import { viteSingleFile } from 'vite-plugin-singlefile';
import viteSingleFileEscaped from 'vite-plugin-singlefile-escaped';

export default defineConfig({
  plugins: [viteSingleFile(), viteSingleFileEscaped('const page = "', '";', { quotes: 'double' })],
});
```

The plugin transforms the HTML asset in Vite's output bundle. It requires exactly one HTML asset, which is the output produced by `vite-plugin-singlefile`.

## Options

The positional arguments are `wrapBefore`, `wrapAfter`, and a [`jsesc` options object](https://github.com/mathiasbynens/jsesc#api):

```ts
viteSingleFileEscaped(wrapBefore?, wrapAfter?, jsescOptions?)
```

All arguments are optional. The wrapper strings default to empty strings, and `jsesc` defaults are used when no options are supplied. For example:

```ts
viteSingleFileEscaped('console.log("', '");', { quotes: 'double' });
```

The package includes TypeScript declarations. See the exported function's type for the supported `jsesc` option shape.
